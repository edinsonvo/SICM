# A.2.1.4 — ModelResult, integración y cierre del contrato

`ModelResult` es el objeto de salida común de todos los modelos SICM.

Integra:

- identificación del modelo;
- equilibrio inicial y final;
- curvas antes/después;
- shock opcional;
- mecanismo de transmisión opcional;
- interpretación;
- diagnósticos;
- metadatos.

## Flujo cerrado

`ModelContract → solve() → ModelResult → Research Lab`

Para un escenario con shock:

`equilibrio inicial → shock → equilibrio final → Δ variables → transmisión → ModelResult`

La entrega incluye `build_result()` para validar la coherencia entre shock y
mecanismo de transmisión.

A.2.1 queda cerrado conceptualmente; la siguiente fase implementa el primer
modelo económico concreto.
