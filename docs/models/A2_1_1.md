# A.2.1.1 — Variables, parámetros y ecuaciones

Establece el contrato matemático común para los cuatro modelos económicos de SICM.

- `Variable`: magnitud económica y sus límites.
- `Parameter`: parámetro estructural/calibrable.
- `Equation`: representación declarativa de una relación matemática.
- `ModelContract`: interfaz común y validación cruzada.

No implementa todavía ningún modelo económico concreto.
