# A.2.1.3 — Shock y mecanismo de transmisión

Establece el contrato para representar shocks y su transmisión económica.

## Flujo

`equilibrio inicial → shock → nuevo equilibrio → diferencias → transmisión`

`ModelShock` describe el shock, `TransmissionMechanism` registra la cadena causal
y `ShockResult` reúne el estado inicial, final, transmisión y advertencias.

No contiene todavía reglas particulares de IS-LM, clásico, Keynesiano abierto
o Mundell-Fleming.
